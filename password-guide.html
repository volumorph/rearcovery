Подтверждение мастер-паролем

Экспорт — файл-бэкап

Файл-бэкап содержит ваши данные в зашифрованном виде. Сохраните его туда, где он не потеряется, — это единственный способ перенести хранилище на другой компьютер.

На новом ПК: откройте этот HTML-файл → «Импорт» → выберите скачанный файл → введите мастер-пароль.

Импорт хранилища

Импорт добавит хранилище в список и не затронет существующие. После импорта введите мастер-пароль этого файла — данные появятся после разблокировки.

Или вставьте содержимое файла из буфера обмена:

Смена мастер-пароля

Укрепить шифрование

Пароль не изменится — только удвоится стоимость подбора ключа (PBKDF2: 600 000 → 1 200 000 итераций). Введите мастер-пароль.

Генератор паролей

Генерация происходит на устройстве через криптографический ГСЧ браузера (crypto.getRandomValues).
