Как проверить: сравните хэш на этом экране с хэшем в описании релиза или в README репозитория rearcovery. Совпал — перед вами опубликованный код, можно вводить мастер-пароль. Не совпал или хэша нет — закройте страницу: это не официальная копия.
Проверка сверяет SHA-256 вашего файла с хэшем последнего релиза на GitHub — это единственный запрос к сети (публичные данные о релизе, ничего из вашего хранилища не отправляется). В локальной (file://) копии проверка запускается автоматически при открытии этого окна.
Скачивайте копию кнопкой «⬇️ Скачать локальную копию (HTML)», а не «Сохранить страницу как» в браузере: браузер сохраняет изменённую страницу, байты файла отличаются от опубликованного, и хэш не совпадёт — хотя код будет тот же.

Аккаунт

Подтверждение мастер-паролем

Для подтверждения введите мастер-пароль.

Экспорт — файл-бэкап

Файл-бэкап содержит ваши данные в зашифрованном виде. Сохраните его туда, где он не потеряется, — это единственный способ перенести хранилище на другой компьютер.

На новом ПК: откройте этот HTML-файл → «Импорт» → выберите скачанный файл → введите мастер-пароль.

Импорт хранилища

Импорт добавит хранилище в список и не затронет существующие. После импорта введите мастер-пароль этого файла — данные появятся после разблокировки.

Или вставьте содержимое файла из буфера обмена:

Смена мастер-пароля

Укрепить шифрование

Пароль не изменится — только удвоится стоимость подбора ключа (PBKDF2: 600 000 → 1 200 000 итераций). Введите мастер-пароль.

🌱 Seed-фраза восстановления

Запишите фразу. Она показывается один раз — после закрытия окна увидеть её снова будет нельзя. С помощью неё можно получить доступ к хранилищу, если забыт мастер-пароль.

буфер очистится через 30 с

Проверка: введите слова под номерами из вашей фразы.

🔑 Восстановление доступа по seed-фразе

Введите фразу из 12 слов и задайте новый мастер-пароль. Данные останутся прежними.

⧉ Копия хранилища под новым паролем

Создаётся независимая копия всех данных с новым мастер-паролем. Текущее хранилище и его пароль не меняются. Копия появится в списке хранилищ и сразу скачается файлом .json.

⚙ Настройки

Если хранилище открыто и вы не касаетесь клавиатуры/мыши указанное время — приложение автоматически заблокируется.
Буфер очищается, только если в нём всё ещё лежит скопированный секрет — чужие данные не затираются.

Генератор паролей

Генерация происходит на устройстве через криптографический ГСЧ браузера (crypto.getRandomValues).
