# AGENTS.md — инструкции для разработки

Проект: **Путеводитель по паролям** — офлайн-сейф паролей с маршрутами восстановления. Это инструкция для ИИ-агентов и разработчиков, которые будут изменять код. Подробное устройство — в `ARCHITECTURE.md`.

## Структура проекта

| Файл | Назначение |
|---|---|
| `password-guide.html` | **Всё приложение**: стили, разметка, логика. Один самодостаточный файл. |
| `index.html` | Редирект на `password-guide.html` (для GitHub Pages). Не содержит логики. |
| `README.md` | Описание, инструкция для пользователей, блок «Версия и проверка» (хэш обновляет CI). |
| `.github/workflows/deploy.yml` | CI: хэш → README → релиз `v1.0.N` → ветка `gh-pages`. |
| `ARCHITECTURE.md` | Устройство кода, модель данных, криптография. |

## Железные правила

1. **Один файл, ноль зависимостей.** Всё живёт в `password-guide.html`: без внешних библиотек, без CDN, без запросов в сеть (единственное исключение — необязательный `fetch` исходника для хэша/скачивания копии, и он перехватывает ошибки). Приложение должно работать двойным кликом по файлу (`file://`) и офлайн.
2. **Не ломать формат бэкапа.** Зашифрованный блоб: `{app:'password-vault', version:1, kdf:'PBKDF2-SHA256', iterations, salt, iv, ct}`. Валидация — `validBlob()`. Менять формат только с миграцией и повышением `version`.
3. **Криптографию не ослаблять.** PBKDF2-SHA256, 600 000 итераций (`KDF_ITERATIONS`), AES-256-GCM. Мастер-пароль нигде не хранится; ключ выводится на клиенте.
4. **Любое изменение или удаление аккаунта — только через подтверждение мастер-паролем.** Используй существующий поток `requestAuth('edit'|'delete', id)` → `modal-auth` → `confirmAuth()`. Не добавляй «дыр», где редактирование/удаление доступно без пароля. Создание нового аккаунта остаётся свободным.
5. **Все изменения данных — через `scheduleSave()`** (автосохранение с задержкой 250 мс, перешифровка всего хранилища). Не забывай вызывать его после мутаций `state.vault`.
6. **localStorage:** реестр хранилищ — `pvg.vaults.v1` (`LS_VAULTS`), устаревший одиночный ключ — `pvg.blob.v1` (`LS_KEY`, только для миграции `migrateLegacy()`). Не удаляй миграцию: у пользователей есть старые одиночные хранилища.
7. **Безопасность данных:** никогда не логируй и не выводи мастер-пароли и открытые пароли в консоль/UI-подсказки. Хэш в «О приложении» считается от сырого исходника, а не от DOM с данными.
8. **Стиль — как в файле:** ES5-подобный JS (`var`, `function`-декларации, без стрелок/классов/modules), без сборки. Добавляя код, следуй этому стилю. Идентификаторы функций и элементов — на английском, тексты интерфейса — на русском.
9. **Веб-версия:** GitHub Pages отдаёт ветку `gh-pages`, которую пересобирает CI при пуше в `main`. Не деплой вручную. Правки в коде → `git commit` + `git push origin main` → CI сам обновит README-хэш, релиз и `gh-pages`. Учти: после пуша кода и README хэш в релизе относится к новому файлу.

## Как проверять изменения

Тестового фреймворка нет. Проверяй в браузере (превью), минимум:

1. Создание хранилища → вход по мастер-паролю → блокировка → повторный вход.
2. Добавление аккаунта (с данными восстановления и общим доступом) → автосохранение.
3. «Путеводитель»: маршрут, подсветка на графе, «Проверка безопасности», дубли паролей.
4. Поиск по аккаунтам.
5. Экспорт → импорт в другом окне/браузере (данные открываются по мастер-паролю, ничего не перезаписывается).
6. Изменение/удаление аккаунта: неверный пароль отклоняется, верный — проходит.
7. «О приложении»: хэш совпадает с SHA-256 файла; на веб-версии версия из `VERSION`.
8. Консоль без ошибок.

## Частые точки правок

- Добавить поле в аккаунт: `emptyAccount()` (стартовая схема), `openEditor()`/`readEditorForm()` (форма), `renderGuideDetail()` (шаги маршрута), `accountCard()` (список).
- Новый тип-иконка: `ACCOUNT_TYPES` + глиф-функция рядом с `envGlyph()`/`goGlyph()`.
- Новое правило риска: `computeRisks()`.
- Граф: `renderGraph()`, `updateChainHighlight()`, `vaultLayout()`/`ensureLayout()` (позиции узлов и камера сохраняются в `state.vault.layout`).
- Экран/модалка: HTML-блок в `<body>`, `showScreen()`/`openModal()`.
